Bewohnerverhalten

Ferhat Altun · Kommandos Ro1 … Roi · Ra · Ri · Re

Bewohnerverhalten: Der Bewohner führt die Kommandos Ro1, Ro2 … Roi aus. Ro: das Kommando wird gesprochen (Gedankenblase in Weiß-Grün). Ra: ähnlich, das Kommando wird mit der Körpermotorik unbewusst ausgeführt (Schwarz-Weiß). Ri: der Gedanke davor. Re: eine Re-Menge wird verwendet oder es wird Bezug darauf genommen, hier über das Handy aus der Tasche, dessen Bildschirm die Re-Menge zeigt. Jeder Schritt erzeugt am Boden die gestreckte Ro-Ra-Ri-Re-Menge (Ro = links lang, Ra = beide gleich, Ri = abwechselnd, Re = rechts lang). Die Kommandos sind Beispiele, das Hirnareal-Modell ist eine grobe schematische Näherung ohne echte Daten.

Der entfernteste Punkt ähnelt einer for-Schleife: Der Startwert ist die Senke am Kopf, jeder Schritt rückt eine gestreckte Ro-Ra-Ri-Re-Menge weiter in Richtung Quelle, und der entfernteste sichtbare Punkt ist die Abbruchbedingung. Ein Ri-Schritt kehrt die Zählrichtung um, wie ein Wechsel von i++ zu i--.

for (i = Senke; i != entferntesterPunkt; i += richtung) {
  Ro(); Ra(); Ri(); Re();   // ein Schritt
  if (schritt == Ri) richtung = -richtung;
}
